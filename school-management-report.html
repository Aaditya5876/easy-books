AI Features

5 features · Gemini 2.0 Flash · requires GEMINI_API_KEY
Feature Where it appears What it does
AI  Class Insights School Dashboard Analyses total students, class count, today's attendance — returns actionable observations for the principal
AI  Notice Generator Notices → Post Notice Writes a full formal notice from just a topic/title and audience selection
AI  Homework Description Homework → Add Homework Generates clear homework instructions from subject, topic, class name, and due date
AI  Fee Reminder SMS Fees → Invoice row Sends a personalised SMS reminder to the student's guardian — AI-composed, delivered via Sparrow SMS
AI  Report Card Comment Exams → Report Card Writes a teacher-style comment based on the student's per-subject marks and overall percentage
